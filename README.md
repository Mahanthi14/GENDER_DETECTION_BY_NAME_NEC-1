# Gender Detection by Name using Machine Learning

## Overview

Gender Detection by Name is a Machine Learning web application that predicts a person's gender based on their name. The system uses a classification algorithm trained on a dataset of male and female names and provides real-time predictions through a user-friendly Flask web interface.

## Features

* Predicts gender from a given name
* Machine Learning-based classification model
* Simple and responsive web interface
* Fast and accurate predictions
* Easy-to-use Flask application
* Clean project structure for learning and deployment

## Technologies Used

* Python
* Flask
* Pandas
* Scikit-learn
* Joblib
* HTML
* CSS

## Machine Learning Workflow

1. Data Collection and Preprocessing
2. Feature Extraction from Names
3. Model Training using Classification Algorithm
4. Model Serialization using Joblib
5. Prediction through Flask Web Application

## Project Structure

* datasets/ – Dataset containing names and gender labels
* models/ – Trained machine learning model files
* templates/ – HTML pages
* static/ – CSS styling files
* utils/ – Data preprocessing functions
* train_model.py – Model training script
* app.py – Flask application

## How to Run

1. Install dependencies using requirements.txt
2. Train the model using train_model.py
3. Run the Flask application using app.py
4. Open the application in your browser
